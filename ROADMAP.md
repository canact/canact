# Roadmap

Near term: keep the public tree quiet. No GitHub description, topics,
README pitch, or crates.io keywords until the maintainer says launch.

Medium term: launch docs (README, `llms.txt`, About description, topics)
when the maintainer unparks that work. First crates.io publish is a
separate human gate after that.

Longer term: follow open issues labeled
[good first issue](https://github.com/canact/canact/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22)
and
[help wanted](https://github.com/canact/canact/issues?q=is%3Aissue+is%3Aopen+label%3A%22help+wanted%22).
There is no public issue list for launch itself.
